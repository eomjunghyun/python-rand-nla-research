# LastFM Asia Normalized Adjacency에서 Degree-Stratified RP 성능 분석

## 0. 요약

본 실험은 LastFM Asia 그래프에서 normalized adjacency를 사용할 때, 표준 Gaussian Randomized Projection과 Degree-Stratified Randomized Projection의 label 기반 clustering 성능을 비교한 것입니다.

실험의 핵심 질문은 다음과 같습니다.

1. Power-law degree structure를 갖는 실제 그래프에서 degree-stratified sketch가 표준 Gaussian sketch보다 label 구조를 더 잘 보존하는지 확인합니다.
2. Oversampling dimension `r`이 증가할 때 두 방법의 성능 차이가 어떻게 변하는지 확인합니다.
3. 성능 개선이 전체 node에서만 나타나는지, 특정 degree group에서 더 강하게 나타나는지 확인합니다.

주요 결론은 다음과 같습니다.

> **LastFM Asia의 normalized adjacency 조건에서 Degree-Stratified RP는 `r=10` 이후 Gaussian RP보다 높은 Macro F1, ARI, NMI를 보였습니다. 개선폭은 특히 degree 3-8의 mid-degree node group에서 가장 크게 나타났습니다.**

전체 node 기준 주요 결과는 다음과 같습니다.

| r | Gaussian RP Macro F1 | Degree-Stratified RP Macro F1 | 개선폭 |
|---:|---:|---:|---:|
| 10 | 0.2239 | **0.2757** | **+0.0518** |
| 20 | 0.2326 | **0.2965** | **+0.0639** |
| 40 | 0.2654 | **0.3500** | **+0.0846** |

Mid-degree node group에서는 개선폭이 더 크게 관찰되었습니다.

| r | Gaussian RP Macro F1 | Degree-Stratified RP Macro F1 | 개선폭 |
|---:|---:|---:|---:|
| 10 | 0.2003 | **0.2685** | **+0.0682** |
| 20 | 0.2123 | **0.2904** | **+0.0781** |
| 40 | 0.2402 | **0.3507** | **+0.1105** |

이번 실험에서는 Gaussian test matrix의 entry variance를 sketch dimension으로 나누는 scaling을 적용했습니다. 즉 Gaussian RP는 `Omega_ij ~ N(0, 1/ell)`, DS-RP는 bucket별 `G_j ~ N(0, 1/ell_j)`를 사용했습니다. 이 scaling은 randomized eigenspace approximation에서 column space를 바꾸지 않는 형태이므로, label 성능 지표는 unscaled Gaussian 실험과 동일하게 재현되었습니다.

## 1. 실험 목적

Power-law graph에서는 대부분의 node가 낮은 degree를 갖고, 소수의 hub node가 매우 높은 degree를 갖습니다. 이러한 degree heterogeneity는 spectral embedding에서 중요한 영향을 줄 수 있습니다.

표준 Gaussian RP는 모든 node coordinate를 동일한 방식으로 섞는 degree-blind sketch입니다.

```text
Y = S Omega
```

반면 Degree-Stratified RP는 node를 degree scale별 bucket으로 나누고, 각 bucket에 별도의 sketch dimension을 배정합니다.

```text
Y = [S[:, B_1]G_1, S[:, B_2]G_2, ..., S[:, B_s]G_s]
```

이 방식은 low-degree, mid-degree, high-degree 영역의 정보가 sketch에 명시적으로 반영되도록 설계한 것입니다. 본 실험은 이 아이디어가 실제 LastFM Asia 그래프에서 clustering 성능 향상으로 이어지는지 확인하는 것을 목표로 합니다.

Degree Gini와 tail log-log CCDF R²가 높으므로, LastFM Asia는 power-law 성격이 강한 그래프라고 볼 수 있습니다.

### 2.2 Graph operator

본 실험에서는 raw adjacency `A`가 아니라 normalized adjacency를 사용했습니다.

```text
S = D^{-1/2} A D^{-1/2}
```

더 일반적으로는 다음 degree-tempered operator의 특수한 경우입니다.

```text
S_{alpha,tau} = D_tau^{-alpha} A D_tau^{-alpha}
D_tau = D + tau I
```

이번 실험에서는 다음 값을 고정했습니다.

| Parameter | Value |
|---|---:|
| `alpha` | 0.5 |
| `tau` | 0 |
| `q` | 1 |
| `k` | 18 |
| `r` | 0, 2, 5, 10, 20, 40 |
| `reps` | 10 |
| `kmeans_n_init` | 20 |

즉 본 실험은 pure normalized adjacency 조건에서 두 randomized projection 방법을 비교한 것입니다.

## 3. 비교 방법

### 3.1 Gaussian RP

Gaussian RP는 전체 node coordinate에 대해 하나의 dense Gaussian test matrix를 사용합니다.

```text
Omega in R^{n x ell}
Omega_ij ~ N(0, 1/ell)
Y = S Omega
```

여기서 `ell = k + r`입니다. 모든 node coordinate가 같은 random sketch matrix 안에서 함께 섞이므로, degree scale별 정보를 따로 보장하지는 않습니다.

### 3.2 Degree-Stratified RP

Degree-Stratified RP는 먼저 raw graph degree를 기준으로 node를 logarithmic bucket으로 나눕니다.

```text
B_j = { i : 2^j <= d_i < 2^{j+1} }
```

각 bucket의 mass는 다음과 같이 정의했습니다.

```text
M_j = sum_{i in B_j} d_i
```

전체 sketch dimension `ell = k+r`은 bucket mass의 square root에 비례하도록 배정했습니다.

```text
ell_j approximately proportional to sqrt(M_j)
```

이후 각 bucket에 대해 별도의 Gaussian matrix를 만들고, bucket별 sketch를 계산합니다.

```text
G_j ~ N(0, 1/ell_j)^{|B_j| x ell_j}
Y_j = S[:, B_j] G_j
Y = [Y_1, ..., Y_s]
```

이 설계는 hub bucket에 더 많은 sketch dimension을 주되, mass에 정비례시키지는 않기 때문에 hub bucket이 전체 sketch budget을 독점하지 않도록 합니다.

## 4. 평가 방법

각 방법으로 approximate eigenvectors를 구한 뒤, row normalization과 k-means clustering을 적용했습니다. Clustering 결과는 실제 label과 비교했습니다.

사용한 지표는 다음과 같습니다.

| 지표 | 의미 |
|---|---|
| Macro F1 | Hungarian matching 후 class별 F1을 평균 |
| ARI | Adjusted Rand Index |
| NMI | Normalized Mutual Information |

전체 node뿐 아니라 degree group별 성능도 함께 평가했습니다.

| Group | 조건 | Node 수 | 포함 class 수 |
|---|---|---:|---:|
| `all` | 전체 node | 7,624 | 18 |
| `low_deg_1_2` | degree 1-2 | 2,942 | 18 |
| `mid_deg_3_8` | degree 3-8 | 2,847 | 18 |
| `high_deg_9_plus` | degree 9 이상 | 1,835 | 17 |

위 degree group은 결과 해석을 위한 evaluation group입니다. 알고리즘 내부 bucket은 logarithmic degree bucket을 그대로 사용했습니다.

## 9. Scaling에 대한 해석

이번 실험에서는 Gaussian test matrix의 entry variance를 sketch dimension으로 나누었습니다.

```text
Gaussian RP: Omega -> Omega / sqrt(ell)
DS-RP:       G_j -> G_j / sqrt(ell_j)
```

일반적인 random projection embedding에서는 이러한 scaling이 norm preservation 관점에서 자연스럽습니다. 그러나 본 알고리즘은 random projection 결과 자체를 최종 embedding으로 쓰는 것이 아니라, `range(S Omega)` 또는 `range([S[:,B_j]G_j]_j)`를 통해 approximate eigenspace를 구합니다.

따라서 위 scaling은 각 sketch block에 nonzero scalar를 곱하는 효과를 가지며, exact arithmetic에서는 column space를 바꾸지 않습니다. 실제 실험에서도 scaled version과 unscaled version의 label 성능 지표는 동일하게 재현되었습니다.

이 결과는 DS-RP의 성능 개선이 단순한 Gaussian variance scaling 때문이 아니라, degree scale별 sketch 구조에서 나온다는 점을 시사합니다.

## 10. 결론

본 실험에서는 LastFM Asia normalized adjacency 조건에서 Degree-Stratified RP가 Gaussian RP보다 더 좋은 label 기반 clustering 성능을 보이는 구간이 명확하게 관찰되었습니다.

핵심 결과는 다음과 같습니다.

- 전체 node 기준으로 `r=10` 이후 DS-RP가 Macro F1, ARI, NMI에서 모두 Gaussian RP보다 높았습니다.
- `r=40`에서 전체 Macro F1은 Gaussian RP 0.2654, DS-RP 0.3500으로 개선폭은 +0.0846입니다.
- 가장 큰 개선은 mid-degree group에서 나타났으며, `r=40` 기준 Macro F1 개선폭은 +0.1105입니다.
- Scaling을 적용해도 성능 결과는 기존 unscaled 실험과 동일하게 재현되었습니다.

따라서 본 실험은 다음 주장을 뒷받침합니다.

> **Power-law graph에서 Gaussian sketch가 충분히 degree-scale별 구조를 보존하지 못하는 구간이 존재하며, Degree-Stratified RP는 이 구간에서 label 구조를 더 잘 보존할 수 있습니다.**
